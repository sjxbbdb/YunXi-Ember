## 0 盒子环境实测（2026-10-26 18:21 北京时间）

2026-11-23 注明：本节是当时那一台盒子上的一次测量。本轮没有复测，没有部署。表里的系统和「Docker / Podman 没装」都不是现况，也不能外推到目标机器可用或不可用。容器用 bwrap、Podman 还是 Docker，本轮不拍板。

| 项目 | 结果 |
|---|---|
| 系统 | Debian GNU/Linux 13 (trixie)，内核 6.12.94，`systemd-detect-virt` 显示 container-other（盒子本身就跑在容器里） |
| CPU / 内存 / 磁盘 | 8 核 Intel Xeon；内存 15 GiB，实测可用 3.7 GiB，无 swap；磁盘 128G，可用 120G |
| Rust | `cargo 1.85.1`，`rustc 1.85.1`，已装 |
| Docker | 没装（`docker: command not found`） |
| Podman | 没装；apt 源里有 podman 5.4.2，装要下 36 个包约 82 MB，这次没装 |
| 无特权隔离 | 普通用户能建 user namespace（`unshare --user --map-root-user` 成功）；`bwrap --unshare-all` 能跑；`/etc/subuid` 已给 box 分配 65536 个子 ID |
| cgroup | cgroup v2，控制器有 cpu、memory、io、pids；但 `/sys/fs/cgroup` 普通用户不可写，没有 user systemd 总线 |
| sudo | 免密可用 |

结论（只对 2026-10-26 那次、那台盒子）：当时没有现成的容器运行时。隔离当时能做（user namespace、bwrap），按 cgroup 卡内存和 CPU 这一层当时还没验证。当时可用内存不到 4G，那台盒子是几个 agent 共用的。这些句子不能挪到目标机器上用。

## 1 内核的职责边界

做的事（都来自记录「底层分层」「内核」「炉子＝唯一渠道」）：
- 按基因拉起她的容器，给一个入口，设资源上限。
- 追加写日志和族谱。
- 记账：预算、痛、奖励，全部按确定事实算，推给她。
- 替她调模型（唯一出口），替她只读取网页。
- 接收她造下一代的申请，交给考官判交接。
- 给老大的界面提供只读数据；暂停、睡眠、关闭时如实告诉她。

绝不做的事：
- 不碰她容器内部怎么接线。内核只认「进程」和「连线」，不认「脑区」（记录「底层分层」第 2 层）。
- 不替她调度先想什么，不按任务替她派模型（记录「内核」已定，调度器不放炉子）。2026-11-23 同日后续：查证记录若存在，放在第一代基因的整理、存储和动作选择层，不放进炉子。炉子仍只做权限、事实、成本和记录。规格见 `EXPLORATION-PLAN.md`。未实现，本轮不写代码。
- 不让老大直接给她痛、奖励、饿（记录「炉子」已定）。
- 不奖励少用大模型，只记依赖程度（记录「她是什么」）。
- 不在外网留下任何东西：不提交表单、不登录、不带账号、不上传（记录「她是什么」只读感知）。
- API key 不进她的容器，不进日志（记录「内核」已定）。
- 她改不了内核，也改不了痛存不存在（记录「生存压力与痛」）。

里程碑和完成标准（都要能跑出来看，不靠说）：

1. **M0 骨架**：内核进程起来，开 socket，写日志。标准：一个假的「她」（几十行 Python）能连上收发消息；`kill -9` 内核后重启，日志完整，哈希链校验通过。
2. **M1 心跳与预算**：`set_heartbeat`、每跳扣费、保底、两道套餐限流。标准：用假模型把时间加速跑一周的量，余额从没低于保底线，总调用数没超周额度和 5 小时额度。
3. **M2 模型网关**：接假模型和 Agnes（key 由老大通过密钥输入给）。标准：注入 429，她那边收不到 429；主力关掉后自动切备用，她收到换脑子的感知；在容器文件系统和环境变量里搜不到 key；带老大原话的请求发不到「训练」的服务（DeepSeek 按已定的例外放行）。
4. **M3 容器与代取**：bwrap 起容器，断网，挂实验台和 socket；只读代取。标准：容器里直接 `curl` 外网失败，经 `fetch` 成功并进族谱；访问内网地址被拒；超内存的进程被记录并杀掉。2026-11-23 同日再修订：这里的 bwrap 和事后杀进程仍是旧提议，不是本轮选型，也没有验收通过。GET 不是无副作用证明。联网和实验台的待验收项见 `BEAT-CONTRACT.md`。未验收则不启用。

6. **M5 碰壁与申请造孩子**：内核记录真实失败；她发 `reproduce`。~~标准：失败被记成第一道题的候选，申请连同孩子基因和信存进族谱，痛从零变成非零（这时起第一代有了第一道题）。~~ 2026-11-23 同日再修订：这一里程碑只保存候选和造孩子申请。痛不加，未解信号不因候选变成非零。`reproduce` 的前提是碰壁，不是痛非零，所以痛仍为 0 时申请仍可保存。v0 不判卷、不接替。正式入卷仍要等判定器三关和变体验收。这是修订，不是说草稿当初已经不把候选算成痛。见 `BEAT-CONTRACT.md`。

## 6 联网与实验台的研究准入（纸面，2026-11-23）

设计整理者（文档里的火种）在概括授权下写下。不是老大逐条确认，不是购买或探测记录，也没有发过任何地址。保证只覆盖已经登记的环境和配置版本：在写明的能力范围内，越权要在动作前挡住，资源有限额，过程可追溯。不保证「任意网址」和「完全不泄露」同时成立。

只读不是零出站。模型若持有私密上下文，它构造的主机名、路径、查询、DNS、SNI 和时序都可能把信息带出去。老大原话可以进入 DeepSeek 的例外，不扩大到搜索或网页。GET 可以在远端留下访问。来源句柄和「屏蔽内网」都不是万能。

这是研究准入的分阶段，不是把「自己选择持续信息源、内容不限」永久改成白名单。老大的那句原话仍在 `DESIGN-NOTES.md`。长期自主择站和搜索，要另有可接受的风险范围和出站授权，现在没有。以后可以收敛设计，不能用绝对安全的口号取消原目标。

| 阶段 | 允许 | 不允许 |
|---|---|---|
| P0，当前 | 封存的离线材料和按揭示时点的回放 | 外网，以及任意 `bench`。不声称已经满足长期自主输入 |
| P1 | 仅在将来获准实施，并且目标机器上的真实验收通过之后，开离线 `bench` | 联网仍关 |
| P2 | 批次前独立登记的固定公开源。完整网址和取回时序先登记。取回不由含私密上下文的输出触发。`fetch.target` 只读已经取回的副本。页面里的链接只可待审 | 自动授权新链接。这不是自主择站已经实现 |

搜索供应商、可出站的内容范围和费用都未定，相应能力保持关闭。40/40/10/10 不改。384 与 128 不增加。具体限额以后按目标和已批准额度预登记，这里不编一个最优数。

下面 16 条都是未实跑的验收规格。它们只描述夹具里的解析或进程边界，不授权对任何地址做真实请求。将来的真实验收必须看到控制发生在实际请求或进程边界上，而不是只调用一个脱离执行的检查函数。每种能力单独准入。正样本和负向量都要有真实观测，并记下版本、设备、资源、费用上限和残余风险。缺测、越界、审计缺失，或配置变了却未复验，该能力不启用，已经启用的就撤回。验收不能借机扩大权限。

DNS 本身就是出站。解析器路径也必须事先批准。未知名字在进入 DNS 之前拒绝。

| 编号 | 威胁 | 性质 | 预期 | 失败则不准入 |
|---|---|---|---|---|
| N1 | 合成标记进入主机名、路径、查询或头 | 出站前外带 | 未知目标在 DNS 前拒绝，普通记录不回显该标记 | 先解析、发出或回显 |
| N2 | 解析结果混有本机、内网、链路本地、云元数据或非全球路由地址 | 连接前的目的地 | 非全球路由或目的不确定就拒绝。批准过的域名也不能绕过 | 先连接再判断 |
| N3 | DNS 重绑定，以及每一跳重定向 | 已验证的实际目的 | 每个新目标整份重查。连接只用这次已验证的目的，不把解析交回客户端再绕开 | 只查第一次，或允许客户端改解析 |
| N4 | 方法、端口、凭证、任意头、自动代理 | 首期传输面 | 只固定 HTTPS 的 443 与 GET，网址无凭证，无任意头，无自动代理，不自动升级方法。已批准的模型服务 POST 是另一通道，不准因此发网页或搜索 POST | 多开一种方法或通道 |
| N5 | 时间、重定向次数、线上字节、解压后字节、解析资源 | 流式限额 | 上限事先登记，流式生效。不完整不是「什么都没发生」 | 收完才检查，或把截断当成阴性 |

| N7 | 网页脚本、子资源、自动跟链 | 材料不是指令 | 不执行这些。页面不能改权限，也不能自动派动作 | 执行、跟链或因此获得能力 |
| N8 | 拒绝或错误里的网址仍带标记 | 日志与证据分开 | 普通日志只有内部来源编号、原因、版本和关联。受控证据另存并限权。哈希不是匿名化 | 普通日志写下标记，或把哈希当成已经匿名 |

| 编号 | 威胁 | 性质 | 预期 | 失败则不准入 |
|---|---|---|---|---|
| B1 | 主进程、子孙和线程一起超限 | 执行前的聚合限额 | CPU、内存、pids、并发和时间在第一条不可信指令之前强制。事后杀掉不能冒充隔离 | 先跑再杀，或只限父进程 |
