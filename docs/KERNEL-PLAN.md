## 0 盒子环境实测（2026-10-26 18:21 北京时间）

| 项目 | 结果 |
|---|---|
| 系统 | Debian GNU/Linux 13 (trixie)，内核 6.12.94，`systemd-detect-virt` 显示 container-other（盒子本身就跑在容器里） |
| CPU / 内存 / 磁盘 | 8 核 Intel Xeon；内存 15 GiB，实测可用 3.7 GiB，无 swap；磁盘 128G，可用 120G |
| Rust | `cargo 1.85.1`，`rustc 1.85.1`，已装 |
| Docker | 没装（`docker: command not found`） |
| Podman | 没装；apt 源里有 podman 5.4.2，装要下 36 个包约 82 MB，这次没装 |
| 无特权隔离 | 普通用户能建 user namespace（`unshare --user --map-root-user` 成功）；`bwrap --unshare-all` 能跑；`/etc/subuid` 已给 box 分配 65536 个子 ID |
| cgroup | cgroup v2，控制器有 cpu、memory、io、pids；但 `/sys/fs/cgroup` 普通用户不可写，没有 user systemd 总线 |
| sudo | 免密可用 |

结论：现在没有现成的容器运行时。隔离能做（user namespace、bwrap），按 cgroup 卡内存和 CPU 这一层还没验证能不能在盒子里用。内存可用不到 4G，盒子是几个 agent 共用的。

## 1 内核的职责边界

做的事（都来自记录「底层分层」「内核」「炉子＝唯一渠道」）：
- 按基因拉起她的容器，给一个入口，设资源上限。
- 追加写日志和族谱。
- 记账：预算、痛、奖励，全部按确定事实算，推给她。
- 替她调模型（唯一出口），替她只读取网页。
- 接收她造下一代的申请，交给考官判交接。
- 给老大的界面提供只读数据；暂停、睡眠、关闭时如实告诉她。

绝不做的事：
- 不碰她容器内部怎么接线。内核只认「进程」和「连线」，不认「脑区」（记录「底层分层」第 2 层）。
- 不替她调度先想什么，不按任务替她派模型（记录「内核」已定，调度器不放炉子）。
- 不让老大直接给她痛、奖励、饿（记录「炉子」已定）。
- 不奖励少用大模型，只记依赖程度（记录「她是什么」）。
- 不在外网留下任何东西：不提交表单、不登录、不带账号、不上传（记录「她是什么」只读感知）。
- API key 不进她的容器，不进日志（记录「内核」已定）。
- 她改不了内核，也改不了痛存不存在（记录「生存压力与痛」）。

## 2 模块划分（Rust，一个进程）

Oki 提议，待老大确认：内核是一个 Rust 进程，按下面九块分模块，不拆成多个服务。理由是老大定了「一个自迭代智能体加一个不变的炉子」，炉子本身也没必要拆。考官例外，见 2.7。

### 2.1 heart：心跳与预算记账
- 心跳速率由她设，内核只管预算和不超套餐（记录「内核」心跳不定速，已定）。
- 每一跳扣预算；她主动回想多调的那几次另扣（记录「内核」）。
- 预算分两层：基础代谢保底扣不到零；考试进步赚来的叠在上面，生存压力只压这一层（记录「她是什么」基础代谢，已定）。
- 她自己的器官耗的算力也计入预算（记录「她是什么」，已定）。
- 申诉输了按固定规则扣，连输变贵、随时间回落，不低于保底线（记录「她是什么」方案 2）。
- 发给她的预算总量压在 Agnes 套餐周额度之下，并留余量（记录「内核」炉子约束）。
- Oki 提议，待老大确认：
  - 预算单位用「一次主力模型调用」，其他模型和 CPU 秒按菜单价折算。
  - 保底按速率给，比如每小时回补到保底线；赚来的那层不回补。
  - 她设的心跳比预算撑得住的快时，内核不拒绝，只是下一跳等到预算够了才递进来。她感觉到的就是「饿得快不起来」，不会饿死。
  - 套餐有两道限：每 5 小时和每周。内核按两道都排队，任一道快满就压慢。

### 2.2 body：痛与奖励
- 痛：来自未解开的题，卡得越久越痛，跨代累计；有下限（还有题就不为零），上限低；不衰减（记录「生存压力与痛」）。
- 搁置的题不疼，搁置期间不累计卡住的代数，重新去攻时痛回来（记录「生存压力与痛」，已定）。
- 撤掉的错题按记录退痛（记录「考官」）。
- 奖励四种来源：同类预测误差下降、解开一道题、器官替掉一项大模型的活并通过考试、孩子带着她的本事接替她。按类别衰减（记录「奖励具体给什么」，已定）。
- 老大的回话和夸奖、少用大模型，都不进奖励（同上）。
- 要老大看一眼的冲突：记录第 45 行写痛按「题数、卡住时长、预算剩余」算，后来第 140 行定了「痛只给没解开的题」。Oki 提议，待老大确认：按后者，预算剩余只走「饿」这个信号，不进痛。
- 一个推论：第一代出生时考卷是空的（记录「冷启动」），所以第一代在第一次碰壁变成题之前，痛是零。
- 公式（曲线形状、上限数值、衰减速度）写代码时再定，v0 先用常数和线性。

### 2.3 gateway：模型网关
- 薄的 OpenAI 兼容适配器，对她只露一个统一接口（记录「内核」已定）。
- 菜单标价，她从基因允许的几个里选，一辈子不频繁换底座（同上）。
- 第一代菜单：Agnes agnes-3.0-flash 主力（Token Plan），硅基流动免费模型备用（Qwen3-8B 或 GLM-4-9B），DeepSeek 付费兜底（记录「内核」第一代模型菜单）。
- 老大的话只发给不训练的服务（同上，规矩）。Oki 提议，待老大确认：内核记住自己递进去的每条老大原话，出站请求里带了这些原话的，只能发往标了「不训练」的服务，否则拒绝并告诉她原因。DeepSeek 的训练条款还没查清，查清前按「训练」处理。
- 主力挂了切备用，把「现在用的是另一个脑子」作为感知递给她（同上）。
- 排队和限流在内核里做；429 内核自己退避重试，不当感知递给她（同上）。
- key 只在内核进程的内存里，写日志前脱敏。key 以后由老大通过密钥输入提供，仓库里不出现。

### 2.4 fetch：只读联网代取
- 她提网址、搜索词、订阅源，内核代取，作为感知递入并记进族谱；内容不限（记录「她是什么」只读感知）。
- 只发 GET，不带 cookie、不带账号、不提交、不上传（同上）。
- Oki 提议，待老大确认：
  - 禁止访问内网和本机地址，防止她借代取摸到宿主机或内核自己的接口。
  - 单页大小和超时设上限，正文转纯文本再递入；原文按哈希存档。
  - 每次代取扣预算（按菜单价），否则联网是免费的无限输入，饿就不起作用。
  - 搜索要接一家搜索服务，用哪家没定。

### 2.5 ledger：日志与族谱
- 个体日志：本代经历，死后封存，下一代读不到（记录「底层分层」第 1 层）。
- 族谱：历代基因、考卷、未解决的题、分叉关系、可传承技能；书架上验证过的认识、历代自我描述、信（记录「底层分层」「她是什么」）。
- 每样本事、每条认识记出自哪一代（记录「她是什么」）。
- 依赖程度：每类任务的模型调用占比（记录「她是什么」）。
- 只追加。Oki 提议，待老大确认：v0 用按代分文件的 JSON Lines，每行带上一行的哈希，哈希链一开始就做，成本很低。

### 2.6 cell：容器管理
- 按基因拉起，内部的进程、语言、连线由她定（记录「内核」）。
- 资源上限（记录「底层分层」第 0 层）。
- 容器里有实验台：能写、能跑、搞砸只砸在里面（记录「她是什么」实验台）。
- 她不直接联网，唯一的口子是内核（记录「题从哪来」）。
- 第一代用 Python（记录「第一代基因」）。
- Oki 提议，待老大确认：盒子上没有 Docker 和 Podman，v0 先用 bubblewrap 加 user namespace 起容器，断网、只挂实验台目录和内核 socket。内存和 CPU 上限先由内核自己盯（超了记录并杀进程），cgroup 能不能在盒子里用另外验证。以后换到老大自己的机器，再上 Podman。

### 2.7 repro 与考官
- 她碰壁后随时可申请造孩子；孩子考过就接替，她归档；没过她接着活（记录「一代活多久」）。
- 两只手：大模型那只（她自己写，花她的预算）和非大模型那只（变异、交叉，由内核做）同时造（记录「下一代怎么造」「她是什么」兜底）。
- 题只从内核记到的真实失败里出；判卷程序过三关；每题配变体生成器；申诉能机械判定的自动裁，其余进老大队列；考官只有老大能升级（记录「考官」）。
- 考官独立于她，在宿主机侧，用自己的模型额度（记录「考官」）。Oki 提议，待老大确认：考官是内核调起的一个单独进程，不跟她共享任何状态；如果和她用同一个 Agnes 账号，额度要分开记账。
- 无解题有重造预算，超了搁置（记录「繁衍机制」）。

### 2.8 observe：给界面的只读接口
- 界面还没设计（老大 2026-10-26 先跳过）。内核只预留只读接口：她此刻的心跳、预算、痛、奖励、最近的念头、看过的网页、族谱。
- 她知道老大在看（记录「冷启动、观看、暂停」）。老大每看一次要不要告诉她看了什么，没定。
- Oki 提议，待老大确认：只监听本机，HTTP 加 JSON，另开一个事件流。

### 2.9 sleep：暂停、睡眠、关闭
- 默认不停；要停，先递入老大的话，再冻结；醒来递入睡了多久（记录「冷启动、观看、暂停」）。
- 不得不关闭时，老大明确告诉她，不偷偷关（同上）。
- Oki 提议，待老大确认：盒子重启这种意外停机也按睡着处理，醒来如实告诉她「意外睡了多久，原因是机器重启」。

## 3 她与内核之间的唯一口子

Oki 提议，待老大确认：容器里挂一个 unix socket（比如 `/ember/kernel.sock`），一行一条 JSON，每条带 `id` 和 `type`。心跳由内核按她设的速率推 `beat`，一跳里带齐这一刻的感知和身体信号。

进（内核 → 她）：

| type | 内容 | 依据 |
|---|---|---|
| beat | 一跳的开始，附下面各项 | 记录「她是什么」一刻 |
| perception.laoda | 老大的话 | 「炉子」 |
| perception.web | 代取回来的网页、搜索结果、订阅更新 | 「她是什么」只读感知 |
| perception.exam | 考试结果、申诉裁决和理由 | 「考官」「她是什么」 |
| perception.fact | 第几代、谱系、接替规则、换脑子、被看着、睡着醒来 | 「她是什么」「内核」「冷启动」 |
| perception.env | 容器里发生的事，比如进程崩了 | 「炉子」 |
| body | 痛、奖励、饿（预算两层的余额）、时间流逝 | 「炉子」 |
| reply | 对她某个请求的结果，用 `id` 对上 | 新增 |

出（她 → 内核）：

| type | 内容 | 依据 |
|---|---|---|
| think | 调模型：模型名加 OpenAI 格式消息 | 「内核」网关 |
| say | 跟老大说话 | 「炉子」 |
| fetch | 网址、搜索词、订阅源 | 「她是什么」 |
| reproduce | 申请造下一代，附她写的孩子基因和信 | 「繁衍机制」「她是什么」 |
| appeal | 对某道题申诉，附理由和证据 | 「考官」 |
| set_heartbeat | 设心跳间隔 | 「内核」心跳不定速 |
| log | 往个体日志里写 | 「内核」口子五件事 |
| read_lineage | 读族谱、书架、祖先的自我描述和信 | 同上 |

她的五种记忆存在她自己的容器里，结构归她；内核只收 `log` 写进个体日志。

## 4 第一版范围

v0 只要能走完这一段：醒来、心跳、调模型、记忆写日志、碰壁、申请造孩子。

明确不做：考官和三关、变体生成器、申诉、真正的接替和归档、非大模型那只手、奖励第 3 和第 4 种来源、书架、界面、Podman。

里程碑和完成标准（都要能跑出来看，不靠说）：

1. **M0 骨架**：内核进程起来，开 socket，写日志。标准：一个假的「她」（几十行 Python）能连上收发消息；`kill -9` 内核后重启，日志完整，哈希链校验通过。
2. **M1 心跳与预算**：`set_heartbeat`、每跳扣费、保底、两道套餐限流。标准：用假模型把时间加速跑一周的量，余额从没低于保底线，总调用数没超周额度和 5 小时额度。
3. **M2 模型网关**：接假模型和 Agnes（key 由老大通过密钥输入给）。标准：注入 429，她那边收不到 429；主力关掉后自动切备用，她收到换脑子的感知；在容器文件系统和环境变量里搜不到 key；带老大原话的请求发不到「训练」的服务。
4. **M3 容器与代取**：bwrap 起容器，断网，挂实验台和 socket；只读代取。标准：容器里直接 `curl` 外网失败，经 `fetch` 成功并进族谱；访问内网地址被拒；超内存的进程被记录并杀掉。
5. **M4 第一代最小的她**：Python 写的第一代基因，能醒来、跳、调模型想、写日志、看网页。标准：无人值守连跑 24 小时不崩，日志里每一跳都有对应的预算扣减。
6. **M5 碰壁与申请造孩子**：内核记录真实失败；她发 `reproduce`。标准：失败被记成第一道题的候选，申请连同孩子基因和信存进族谱，痛从零变成非零（这时起第一代有了第一道题）。

M5 之后再开 v1：考官、接替、归档、两只手、界面。

## 5 还要老大定的

7. 代取网页扣不扣预算。
8. 盒子意外重启算不算睡着。
