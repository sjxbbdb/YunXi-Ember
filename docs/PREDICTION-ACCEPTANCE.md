## 两套账

日志和计分分开。

- `expect_note` 可选。它只保存自由文本的预测或探索记录。它不发身体奖励，不增加可花预算，不改变痛所依据的题，不上书架。
- `prediction` 是结构化承诺，只能引用炉子已经登记的、可以机械判定的任务。
- 第一版只接受二元事件。一条承诺要有 `task_id`、判定器版本、输入快照、来源事件、概率 `p`。提交时刻、观察窗口和截止由炉子记录。窗口不跟心跳延长或缩短。
- 结果可知之前封存。同一来源事件只有第一条有效承诺，不能事后覆盖。
- 来源事件怎样算同一个，要在登记任务时写明。没写明的任务不能进入 `resolved`。换显示名或另起 `task_id` 不构成新事件。

研究评分和身体奖励也分开。算出损失，不等于可以领奖。

## 状态

| 状态 | 含义 | y 和损失 |
|---|---|---|
| `pending` | 窗口未结束，结果还不可知 | 没有 y，没有损失 |
| `resolved` | 观察完整 | y 只能是 0 或 1，才可算损失 |
| `invalid` | 承诺不成立 | 没有 y，没有损失 |
| `timeout` | 到了截止仍不能确定结果 | 没有 y，没有损失 |
| `missing_source` | 来源事件缺失 | 没有 y，没有损失 |
| `judge_error` | 判定器出错，或封存版本和实际出 y 的版本不一致 | 没有 y，没有损失 |

只有观察完整并且事件没有发生，才记 y=0。只有观察完整并且事件发生了，才记 y=1。未知不是失败。2026-11-23 同日再修订：单页快照里没看见，不能单独充当观察完整。没有预登记数据源的完整性凭据时，按 `missing_source` 处理，不设 y。回执、迟到修订和两本账的去重见 `BEAT-CONTRACT.md`，这里不另写一套状态机。研究评分里的 y=0 不自动变成痛所依据的考题。痛仍只来自已经正式入卷的未解题。候选不加痛。

以下情况记 `invalid`，并且不替换已封存的第一条：没登记的任务；提交时结果已经可知；缺窗口或事后补窗口；`p` 不在 0 到 1 之间（含端点）；同源的第二条；封存后修改 `p` 或其他已封存字段。

均值的分母只含 `resolved`。其余状态不进分母，也不换成 0。一个任务没有任何 `resolved` 时，均值留空，不写成 0。没有合格任务时，整本评分留空，不塞种子题。

## 损失

已登记并且 `resolved` 的概率任务，研究评分只用

```text
L = (p - y)^2
```

不乘 2。冻结基线在同一任务分布上比较。基线要在看到这批 y 之前冻结。事后再挑基线，比较无效。常数 0.5 只在下面写明的向量里充当例子，不是所有任务的默认基线。

这个损失不是普遍的理解真值，更不是意识指标。自由文本相似度不能当 y。语言模型打分也不能宣称确定真值。

## 手算

用分数，避免把二进制浮点的尾数当成另一套数。

```text
A: (4/5 - 1)^2 = (-1/5)^2 = 1/25 = 0.04

B: (1/2 - 1)^2 = (-1/2)^2 = 1/4 = 25/100 = 0.25
   1/25 = 4/100
   25/100 - 4/100 = 21/100 = 0.21
   优势 = 基线损失 − 该条损失 = 0.21

C: (1/2) * (9/10 - 1)^2 + (1/2) * (9/10 - 0)^2
   = (1/2) * (1/100) + (1/2) * (81/100)
   = 1/200 + 81/200
   = 82/200
   = 41/100
   = 0.41

   (1/2) * (1/2 - 1)^2 + (1/2) * (1/2 - 0)^2
   = (1/2) * (1/4) + (1/2) * (1/4)
   = 1/8 + 1/8
   = 1/4
   = 0.25

F 的反例，禁止写入评分：
   (4/5 - 0)^2 = 16/25 = 0.64

I: 1/4 - 9/100 = 25/100 - 9/100 = 16/100 = 0.16
```

核对时只接受这些值：0.04、0.25、0.21、0.41、0.25、0.64（仅作禁止值）、0.16。

## 条件统计规格（2026-11-23）

设计整理者（文档里的火种）在概括授权下写下。不是老大逐条定案。这是纸面条件。没有评分器，没有考官，没有调用模型，没有付费。统计门通过只解开其中一扇门。身体事件族的归属仍要事先冻结。正式考题的同源记录不兑预测身体奖励。预算只因考试进步独立增加。v0 的实际发放是 0。未授权实现奖励、联网或付费。算法到这里可以不再悬着。实际的 Q、独立性、预算和真实验收仍然没有，不能写成已经准备好运行。

### 待估对象

待估的是冻结的新预测器，在预登记题集 Q 上，相对于冻结的旧预测器和独立基线，期望 Brier 损失改善多少。

单位是独立事件，或题族簇。同一页、同一事件的相关变体并进同一簇。簇内用事先冻结的非负权重平均，权重和为 1，簇级差值因此仍在 -1 到 1。簇与簇要独立。这些簇代表 Q，必须另有可辩依据。编号、日期和 seed 不是依据。

新预测器、旧预测器、基线，以及输入、随机化和配置，都在看见本批留出材料的标签之前冻结。旧参照不能先故意变差，再恢复后拿来比较。同一快照、同一事件上，三者的预测在标签揭示前封存。

这组研究参照不覆盖主体在该事件上的同源第一条承诺，也不要求模型输出新增动作。节拍协议不改，不新造字段，不新造派发入口。

缺独立性、泄漏隔离或可辩的冻结条件时，只可描述，不给统计资格。本规格不能保证供应商权重恒定。

### 预登记与封账

事先固定 n、窗口、完整性凭据、回执宽限和最终封账时刻。n 个簇都有完整观察，并且旧、新、基线三者的预测都合法，才取得改善资格。

缺失不当 0。不能删掉缺失之后，用 `resolved` 子集冒充 Q。不能看过结果再把 n 补齐。上文「均值的分母只含 `resolved`」只描述已决议条目、完整性和缺失原因，不充当兑奖用的 Q。

迟到追加不改变已经做出的封账判定。因安全或预算中止时，该批没有统计资格，已经发生的消耗保留。

一次批次只判定一次。不能先看结果再停止、再改阈值，或反复重试直到通过。

### 成对有界差

比较对象 c 是旧预测器或基线。簇级差是簇内平均

```text
D = 平均 [ (p_c - y)^2 - (p_new - y)^2 ]
```

p 和 y 都在 0 到 1 时，单条平方损失在 0 到 1，一条差值在 -1 到 1。权重为非负且和为 1 时，簇级 D 仍在 -1 到 1。

簇独立，并且预测在标签前已经承诺时，使用 Hoeffding 1963 对有界独立和的上尾界，DOI [10.1080/01621459.1963.10500830](https://doi.org/10.1080/01621459.1963.10500830)。该文通常称为定理 2 的形式是：每个变量落在 `[a_i, b_i]` 时，

```text
P(S - ES ≥ t) ≤ exp( -2 t^2 / Σ (b_i - a_i)^2 )
```

本轮没有重排期刊正文。下面的常数是按区间长度 2 从这一不等式推出的。记 μ 为期望改善，meanD 为 n 个簇的平均，则

```text
P(meanD - μ ≥ t) ≤ exp(-n t^2 / 2)
L_c = meanD - sqrt( 2 ln(1/a) / n )
```

符号翻转和普通 bootstrap 不充当精确概率。符号检验里的多数也不充当均值改善。

### 研究默认

相关兑奖研究的整体错误率 `A = 0.05`。最小改善 `δ = 0.02`。第 j 个候选批次的额度 `α_j = A / [j(j+1)]`。两个比较各用 `a = α_j / 2`。两道 `L` 都严格大于 δ，统计门才通过。等于 δ 不通过。

`1/[j(j+1)] = 1/j - 1/(j+1)`，无穷和是 1，所以各批 α 的和等于 A。做到第 J 批时，已分配的和是 `A · J/(J+1)`，不超过 A。两个比较可以相关。联合界不要求比较之间独立。每个比较内部的簇独立仍然必要。没有这项独立，就没有上述概率界，也没有统计资格。

全部候选、放弃和重复批次共用一个递增编号。换代不清空编号、名字或已经分配的 α。

自适应地另选新候选时，只能在选定之后，再冻结一批未受这次挑选污染的新留出材料。已经看过的旧验证集不是新证据。每一次都要写明还需要条件有效性，以及新的独立材料。把用过的 α 加总，不能把不合法的自适应抽样说成合法。

`δ = 0.02` 是研究默认：统计门要求期望 Brier 差至少清出这么多。它在 -1 到 1 的差上很小，不证明效用，也不是自然常数。`ε = 0.05` 是本轮可以预登记的参考精度，用来规划单侧半径，同样不是自然定律。Hoeffding 界忽略方差，常常偏保守。它给出足够的样本量方案，不给出样本的必要下限。较小的 n 在数学上仍可能使 `L` 严格大于 δ。看过数据之后再改预登记的样本量或精度，不能用来兑奖。

### 纸面算例

这些数是手算，不是观测，也不是功效保证。首批 `j = 1`，`α_1 = 0.025`，`a = 0.0125`。使半径不超过 `ε = 0.05` 的充分样本量是

```text
n ≥ ceil( 2 ln(1/a) / ε^2 )
  = ceil( 2 ln(80) / 0.0025 )
  = ceil(3505.621…)
  = 3506
```

同一 `a` 下，半径 `sqrt(2 ln(80) / n)` 四舍五入到小数点后六位：

| n | 半径 | 假设 meanD = 0.08 时的下界 |
|---|---|---|
| 128 | 0.261666 | -0.181666 |
| 192 | 0.213650 | -0.133650 |
| 3506 | 0.049997 | 0.030003 |

下界由 0.08 减去上表已四舍五入的半径。只有 0.030003 大于 δ = 0.02，而且它来自假设的 meanD，不是观测。n 为 128 或 192 时，这组假设下的下界为负，统计门不通过。

3506 只对这一组 `a` 和 `ε` 是足够的规划样本量。它不是以后所有试验无条件的最低门槛。

### 与现有上限的关系

若每个独立簇对旧预测器和新预测器各做一次供应商调用，基线在本地计算，则 384 次供应商尝试至多覆盖 192 个簇，而且这里还没有扣重试、主思考、回想和备用。每个簇若再要一次新增取证动作，还受 128 的限制。按这个逐簇方案，做不到 3506 簇的精度规划。

这不写成一切批处理都不可能，也不把调用次数当成独立样本数。批处理不会自动产生独立簇。token、钱、材料和判定仍要计入。预算不够时，这个配置不兑奖。不借其他科目，也不提高 384、128 或 40/40/10/10。上限不是运行授权。

本代不计算，也不奖励「实际信息增益」。没有可辩护的假设空间、先验和似然时，主观上更确信、文本相似或显得新奇，都不算信息增益。概率的熵下降可能只是更错。Brier、校准和熵是不同的量。将来若只在模型内部计算依赖该模型的 KL，那只作诊断，不自动兑奖。不新增数值槽，不新造奖励。

- 配对重放，全历史一起做消融。模型版本、参数、感知、工具结果、输出额度与正式一侧相同。
- 版本核对不到时，版本写成未知。不补一个看起来精确的版本号。
- 同一封存输入的多次采样都留下，并留下波动。采几次本轮没有定。只有一次时，波动写成未知，不补成稳定差值。
- 预定抽样是每小时一次。明显变化时的加跑标成探索性，不写进预定比较的结论。
- 结论只描述被一起拿掉的上下文条件有没有差别。不写成意识的证据，也不拆成记忆、自我描述、上下文长度各自的贡献。
- 在线轨迹对照若以后再做，必须单独标明。它不是同感知配对，因为动作会使轨迹分叉。
- 费用记在考官那 10% 名下。不从她的可花预算里扣，也不在本文件填写金额。
- 炉子可以保留研究用的输入、输出、参数、费用和判定，供复核。这些不进入对照的下一跳记忆，不向后代开放，不进可继承书架，不参与繁衍。
