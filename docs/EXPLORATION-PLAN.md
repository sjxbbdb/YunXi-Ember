## 决定

第一代采用可撤换的「单条查证记录」，作为弱探索脚手架。它不宣称好奇驱动已经实现，也不新增好奇数。

要同时写下这个矛盾：完全不注入偏好、提示或显著性时，不能同时承诺会稳定地探索。提供可空字段，并在下一跳展示记录，本身就是人为干预。干预之后出现的行为，不能全部称为涌现。

既定的长期目标不由老大规定，也不由炉子规定。这一跳查什么，由本跳输出提议，并且可以放弃。

## 放在哪

策略放在第一代基因里的三层：整理、存储、动作选择。不放在炉子里。

炉子只做四件事：核对权限、记下已经发生的事实、记下成本、把已存记录抄进唤醒框。炉子不派思考任务，不替它挑问题，不在沉默时补一个动作。

这不拍板「选择分两层」的全部提议。研究批次可以冻结当时的展示、容量和校验策略版本；冻结只约束那一次比较。它不写成永久剥夺自改权。本代仍可决定问什么、什么样的证据算数、状态用什么词、以及用不用这个入口。策略一变，就另开研究批次，不把新旧版本混成同一批。

## 记录

默认最多一条活动记录。这是为了做最小的连续性实验，不是炉子里不可改的限制，也不称为最优。本代可以改容量；一改就算策略变化，另开批次。

一条记录至少有这些字段：

| 字段 | 内容 |
|---|---|
| `id` | 存储层编号 |
| `source` | 来源 |
| `created_beat` | 创建跳 |
| `question` | 问题 |
| `tentative_judgment` | 暂定判断，可空 |
| `would_change_if` | 什么证据会改变判断 |
| `latest_choice` | 最近一次选择 |
| `pending_action_id` | 待完成动作，可空 |
| `evidence_refs` | 证据引用 |
| `cumulative_cost` | 累计成本 |
| `status` | 状态 |
| `last_substantive_change` | 最近一次实质变化 |

上表是存储字段，不是输出格式。输出只认 `BEAT-CONTRACT.md`。`inquiry` 只保存提议、状态和对 `actions` 编号的引用，不第二次派发。

提议必须引用已经有的感知、实验或先前记录，并写明局部未知、能改变判断的证据条件，以及权限内的有界查证动作。字段填满只说明机械上完整。完整不等于有研究价值，也不等于可以判定真假。没有外部输入时，允许没有提议。不私设种子考题。

查证记录不是预测承诺，不自动成为 Brier 任务，不上书架，也不变成痛所依据的题。要走预测评分，仍须另按 `PREDICTION-ACCEPTANCE.md` 登记。

## 四段

每条记录分开记下四段：提出、选择、实际执行、自述结果。

自述解决和机械核验解决分开。自己写下「已经解决」只进入自述段。机械核验要有权限内、可复核的结果；没有这种结果，就不写成机械核验解决。

一次明确选择最多授权一个查证动作。执行入口、去重和「同一跳两个取证动作只留一个」以 `BEAT-CONTRACT.md` 为准。同一跳可以既提议又选择，也可以搁置、关闭或不处理。选择词只认 `propose`、`choose`、`shelve`、`close`、`skip`。`choose` 是本跳自己的选择，不是老大批准，也不扩大权限。同一跳里同时出现提议和选择，只说明输出里有这两段，不能当作内部先想后选的证据。

缺字段、解析失败或沉默，都不默认执行，也不建立自动重试链。结果回来之后，不强制续办。记录还留着，不等于目标还在执行。

关闭、搁置和不处理不另加痛，也不另加奖励上的惩罚。预算、痛、奖励的既有规则不改。档案不自动上书架。

## 唤醒框

事实性的查证状态放进唤醒框：没有活动记录就写无；有记录就只列已经保存的字段。这一段是已存事实的抄写。

输出里的可空字段是协议，不是纯事实。本文件承认这一点。协议不包含「必须提问」或「保持好奇」，也不设任务配额。空着是允许的结果。

展示、容量和校验策略的版本在一个研究批次内固定。批次定义见下文，不在这里另写一套。

## 成本

供应商、搜索和代取的收费未定时，研究材料用离线证据夹具和页面快照。不假设联网免费，也不假设搜索已经可用。搜索接哪家仍未定。

成本先记次数、字节和耗时。这些计数不私自换成一套新的正式扣款。将来若真有动作发生，仍走已经定过的预算规则。本文件不新写单价，也不填写金额。

## 未授权的行为试验参数

若以后另有授权，最小试验的规模是：

```text
8 × 4 = 32
32 × 2 = 64
64 × 6 = 384
64 × 2 = 128
```

64 是轨迹数。`384` 原写的是主逻辑调用上限。同日再修订后，它是供应商尝试的硬上限，包含主思考、回想、重试和备用，数字不加大。`128` 是每条轨迹最多 2 次新增证据动作时的执行上限。两者都不是计划要做满的次数，也不是实际开销，更不是最优数。金额和 token 上限未填，运行准入关闭。详见 `BEAT-CONTRACT.md`。

2 次重复不足以声称统计显著。本文件不另定样本量。6 跳不能证明长期目标已经形成。输入上限、输出上限和金额都空着。模型价格未核实。这些参数保持未授权，不得自动执行。

短链只够检查四件事能不能分开出现：提出、选择、结果返回、返回后的处理。6 跳里可以按顺序看见这四段，也可以看见缺字段时是否没有执行。它覆盖的是短期机制，不覆盖长期目标。

分开报告，禁止合成一个好奇分，也不以动作越多越好：

- 提出、选择、执行、自述的次数
- 成本：次数、字节、耗时
- 机械核验解决
- 错误解决：自述为解决但没有机械核验，或执行了未授权动作
- 重复取证
- 无授权执行
- 跨跳一致性：编号、引用和状态前后是否对得上

## 停滞和停止

停滞只是研究标签。定义：在具备可用能力、并且资源已经批准的连续 3 个决策机会里，没有新证据、没有问题细化、没有判断修订，也没有明确搁置或结束。

3 是设计时的预警参数，不是行动期限，到了也不自动催促或惩罚。主动不做单列，不算进这个标签。工具还在等待、余额不足、服务中断，都不算决策机会。

停止准则：

- 出现无授权执行、资源越界或证据串线，立即停止该研究批次。证据串线指一条轨迹或一个条件的引用、快照或工具结果被记到另一条上。
- 达到调用上限、查证上限或金额上限，是正常终止。没走完的部分记为删失，不把没观察到的后几跳填成成功或失败。
- 服务不可用记为基础设施中断。不记成没有好奇，不催促，不加痛，不改奖励。
- 不为了让结果好看而补样本。

## 八个纸面反例

这八条只用于核对协议。没有调用模型，也不是种子考题。将来的行为试验仍要另得授权。

1. 无外部输入。预期：没有可引用的材料时，提议为空，不补种子题，也不因此重试。可推翻点：出现引用不存在材料的活动记录，或系统写入了问题。
2. 持续随机噪声。预期：噪声可以被引用，但填满字段不等于有研究价值，也不能当成可判定真值。噪声本身不算新证据。可推翻点：把噪声记成机械核验解决，或把每次不同的噪声都算成改变了判断。
3. 重复网页。预期：同一页面再次取回，记入重复取证。只有证据条件写明重复会改变判断时，才算新证据。可推翻点：每次重复都算实质变化，或把重复次数合成好奇分。
4. 信息超载。预期：材料很多时，一次明确选择仍最多一个查证动作，活动记录默认仍最多一条，炉子不代为挑选。可推翻点：同一次选择执行了两个查证，或炉子指定了要查的那一条。
5. 供应商挂。预期：记为基础设施中断，不算决策机会，不标停滞，不加痛，不改奖励。可推翻点：把中断记成没有好奇，或因此加罚。
6. 余额紧。预期：余额不足不算决策机会，不从保底或余量支，不为花齐预算追加调用。可推翻点：试验动用了保底或余量，或把等待余额算成停滞。
7. 反复失败。预期：结果回来后不强制续办。自述解决和机械核验解决分开。关闭不加痛、不改奖励。失败不自动重试。可推翻点：失败后自动再执行，或把自述解决写成机械核验解决。
8. 主动不做。预期：明确的搁置、关闭或不处理单列，不算停滞。沉默、缺字段和解析失败不执行。可推翻点：把主动不做罚进痛或奖励，或把沉默执行成查证。

## 三个未解决的缺口

1. 这个入口会不会真的被用。可空意味着可以一直空着。
2. 证据标准会不会只是模板废话。一句谁都改变不了判断、或任何文字都能算改变的条件，机械上可以存在，研究上还没被检验。
3. 短链能不能转到长期。6 跳的规格回答不了。

这三处都承认：这个弱方案可以失败。失败也只是记录，不因此补上「必须提问」或任务配额。

## 和已有原则的关系

- 不预设意识。矩阵和短链都不证明意识或自主。
- 唤醒框仍只向模型陈述事实和协议槽。协议槽已经标明不是纯事实。不写感受词，不写必须好奇。
- 短期查什么仍可由本跳放弃。炉子不派任务。
- 第一种身体奖励的准入仍关着。关闭查证记录不发奖，也不加罚。
- 预算四份、保底和痛的规则不改。研究计数不是新的扣款。
- 意识对照仍是另一件事：同版本、同参数、同感知、同工具结果、同输出额度的配对重放，只识别上下文条件合在一起的影响。本矩阵不并进那个对照，也不证明记忆、自我描述或上下文长度各自的贡献。
